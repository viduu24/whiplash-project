## S01 — Record availability

The Task 05 record-availability figure was generated from the 33 retained CAMELSH hourly basins for the 1995–2010 study period. The detailed PDF is retained in the project Drive because binary result files are not committed through this GitHub workflow.

Summary: 192,852 expected daily basin records; 146,732 complete 24-hour records; 46,120 incomplete records; overall Q completeness 76.0853%.
